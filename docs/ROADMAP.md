## ديون تقنية معروفة

- `Job.search_blob` يحتاج إعادة حساب دوريًا عند تغيير اسم الشركة (أمر CLI مقترح).
- الإشعارات polling كل 60 ثانية — مقبول الآن، ويحتاج WebSocket/SSE عند النمو.
- لا اختبارات E2E متصفح بعد (pytest يغطي الخدمات والمسارات).
- ملفات `.env` لا تُدار مركزيًا — يُنصح بـ secrets manager عند الفريق.
