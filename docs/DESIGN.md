# الهوية البصرية — مهنة

الهوية مأخوذة من المشروع الأصلي: **الشعار الجديد (بخلفية شفافة/ثلجية) + خط Tajawal**، مع نفس الشعار (`logo.png`) داخل بلاطة داكنة.

## الشعار

| الملف | الاستخدام |
|---|---|
| `app/static/img/logo.png` | شعار مهنة الأساسي بدون خلفية — مشاركة اجتماعية وog:image |
| `app/static/img/logo-mark.png` | شعار مهنة الأساسي بخلفية ثلجية — شريط التنقل، الفوتر، لوحة الإدارة، الأيقونة |

الشعار تم استخدام الملفين المرفقين (بدون خلفية وخلفية ثلجية) كمرجع لتصميم الهوية البصرية للنظام، مع تطبيق لوحة الألوان الجرافيتية `#1E293B` والأزرق `#3B82F6` على عناصر الواجهة.

## الألوان

| Token | القيمة | الاستخدام |
|---|---|---|
| `--brand-500` | `#1E293B` | اللون الأساسي، الأزرار، الشعار |
| `--brand-800` | `#0F0F15` | نص الروابط (تباين ≥ 5:1) |
| `--brand-50` | `#F8FAFC` | خلفيات هادئة، شارات |
| `--accent` | `#3B82F6` | التدرجات والتركيز |
| `--ink-900` | `#1E293B` | النص الأساسي |
| `--paper` | `#F8FAFC` | خلفية الصفحة |
| `--success` | `#15803D` | التوثيق، الحالات الإيجابية |
| `--danger` | `#B42318` | الأخطاء والحذف |

**قاعدة التباين:** لا نص أبيض على برتقالي فاتح. الأزرار البرتقالية تستخدم نصًا داكنًا
(`--ink-900`)، والنص البرتقالي على الأبيض يستخدم `--brand-800`.

## الخطوط

- **Tajawal** (300–900) للعربية والواجهة.
- **Inter** للأرقام والنصوص اللاتينية داخل `dir="ltr"`.
- أحجام: 12 / 13 / 16 / 17 / 20 / 24 / 30 / 38 / 48، وارتفاع سطر 1.75 للنص العربي.

## RTL

- خصائص منطقية فقط: `margin-inline`, `inset-inline`, `padding-block` — لا `left/right`.
- الأرقام الغربية مقصودة (`1,500,000 IQD`) مع `dir="auto"` أو `<bdi>` لمنع انقلاب المدى.
- الأيقونات الاتجاهية تُقلب تلقائيًا عبر CSS عند الحاجة (`arrow-left` في سياق RTL).

## المكوّنات

- **أزرار:** `btn-primary` (جرافيت داكن/نص أبيض `#F8FAFC`)، `btn-accent` (أزرق `#3B82F6`)، `btn-ghost`،
  `btn-soft`، `btn-danger`، `btn-google`.
- **بطاقة وظيفة:** شعار الشركة، العنوان، الشركة/المدينة/شارة التوثيق، شرائح الراتب والنوع
  والخبرة والمنافسة، ثم الوقت وأزرار الحفظ/التقديم.
- **فلاتر:** مجموعة radio/checkbox مع عدّاد نتائج، تعمل بـ GET (قابلة للمشاركة والفهرسة).
- **حالات فارغة:** أيقونة + عنوان + نص + إجراء واضح.
- **إشعارات:** جرس + عدّاد، لوحة تُحمّل عبر HTMX، «تحديد الكل كمقروء» POST.

## إمكانية الوصول

- تباين AA للنصوص الأساسية، وأهداف لمس ≥ 44px.
- `:focus-visible` واضح، رابط «تخطَّ إلى المحتوى»، `aria-label` للأزرار الأيقونية.
- الجداول لها رؤوس، والنماذج لها labels حقيقية (لا placeholder فقط).
- `prefers-reduced-motion` يوقف الحركات.
